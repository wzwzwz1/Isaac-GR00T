# GR00T NPU 多版本环境配置指南

## 背景

全局环境仅安装了一套 Python 3.9 + torch_npu，但项目依赖 `transformers==4.51.3`（`pyproject.toml` 声明），全局却被升级到了 `4.57.6`。新版 transformers 移除了 Eagle 模型处理器依赖的多个 API（`BASE_IMAGE_PROCESSOR_FAST_DOCSTRING`、`VideoInput` 等），导致 processor 无法加载。

需要一套可切换 transformers 版本、且不影响全局环境的环境管理方案。

## 为什么用 virtualenv 而不是 conda

| 方案 | 问题 |
|------|------|
| **conda** | 华为云镜像 repodata 的 zstd 压缩格式与 conda 26.x 不兼容；官方源速度极慢。conda 的独立 Python 也无法直接使用系统的 `torch_npu` C 扩展（`_C.cpython-39-aarch64-linux-gnu.so`） |
| **virtualenv + --system-site-packages** | 直接继承系统所有包（torch、torch_npu、CANN），只隔离 pip 安装的包。零环境开销，启动快 |

## 环境清单

| 环境名 | transformers | Python | torch | torch_npu | 位置 |
|--------|-------------|--------|-------|-----------|------|
| **gr00t-4.51** | 4.51.3 | 3.9.9 | 2.8.0+cpu | 2.8.0.post4 | `/home/wangzhe/venvs/gr00t-4.51` |
| **gr00t-4.57** | 4.57.6 | 3.9.9 | 2.8.0+cpu | 2.8.0.post4 | `/home/wangzhe/venvs/gr00t-4.57` |

- gr00t-4.51: Eagle processor 兼容（匹配 `pyproject.toml`），用于完整 backbone+DiT 推理
- gr00t-4.57: 当前系统兼容，用于已有 benchmark 脚本

## 激活方式

```bash
# Eagle processor 兼容环境 (推荐用于 backbone 推理)
source /home/wangzhe/venvs/activate-4.51.sh

# 当前版本环境
source /home/wangzhe/venvs/activate-4.57.sh
```

激活脚本自动完成：
1. 激活 virtualenv
2. source CANN set_env.sh，设置 NPU 运行时库路径

## 环境结构

```
/home/wangzhe/venvs/
├── activate-4.51.sh          # 一键激活 gr00t-4.51
├── activate-4.57.sh          # 一键激活 gr00t-4.57
├── gr00t-4.51/               # transformers 4.51.3
│   ├── bin/python
│   └── lib/python3.9/site-packages/
│       └── transformers/     # 4.51.3 (覆盖系统 4.57.6)
├── gr00t-4.57/               # transformers 4.57.6
│   ├── bin/python
│   └── lib/python3.9/site-packages/
│       └── transformers/     # 4.57.6
```

系统包（torch、torch_npu、CANN 等）通过 `--system-site-packages` 继承，不在 venv 中重复安装。

## Python 3.9 兼容性修复

项目代码中使用了 Python 3.10+ 的 `X | None` 类型联合语法。以下文件已添加 `from __future__ import annotations` 修复：

| 文件 | 修改内容 |
|------|---------|
| `gr00t/data/dataset/factory.py` | 添加 `from __future__ import annotations` |
| `gr00t/model/gr00t_n1d6/setup.py` | 添加 `from __future__ import annotations` |

## 验证

```bash
source /home/wangzhe/venvs/activate-4.51.sh
python -c "
import gr00t.model
from transformers import AutoProcessor
p = AutoProcessor.from_pretrained('/home/wangzhe/models/GR00T-N1.6-3B')
print('Processor:', type(p).__name__)
print('OK')
"
```

输出：
```
Processor: Gr00tN1d6Processor
OK
```

## 注意事项

1. torch_npu 的 C 扩展绑定 Python 3.9，**不能升级到 Python 3.10+**，否则 NPU 不可用
2. gr00t 项目代码路径 `/home/wangzhe/Isaac-GR00T` 通过 CANN 环境或 `.pth` 文件自动加入 `sys.path`
3. 全局环境的 transformers 4.57.6 不受影响，两个 venv 各自独立
